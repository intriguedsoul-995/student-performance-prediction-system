# Student Performance Prediction System

## Problem Statement

Students may find it difficult to understand their current academic
performance and identify the factors that can affect their results.

Teachers and students may also need a simple method to identify whether
a student is academically at risk.

The Student Performance Prediction System solves this problem by taking
basic student information such as attendance percentage, daily study
hours, and previous examination marks.

The system analyzes this information and generates a predicted
performance score, academic risk level, and personalized recommendations.

## Scope of the Project

The scope of this project includes:

- Taking student details as input
- Accepting attendance percentage
- Accepting daily study hours
- Accepting previous examination marks
- Validating user input
- Calculating a predicted performance score
- Categorizing student performance
- Identifying academic risk
- Providing personalized recommendations
- Displaying a final student report

The project is developed using basic Python programming concepts and does
not require any external libraries.

## Target Users

The target users of this system are:

- Students
- Teachers
- Academic mentors
- Educational institutions

## High-Level Features

### 1. Performance Prediction System

The system calculates a student's predicted performance score using:

- Attendance
- Daily study hours
- Previous examination marks

### 2. Risk Analyzer

The system identifies the student's academic risk level.

Possible risk levels are:

- Low Risk
- Medium Risk
- High Risk

### 3. Recommendation System

The system provides recommendations based on the student's academic
information.

Examples include:

- Improve attendance
- Increase daily study time
- Practice more questions
- Revise weak topics
- Maintain the current study routine

### 4. Input Validation

The system checks that:

- Attendance is between 0 and 100
- Study hours are between 0 and 24
- Previous exam marks are between 0 and 100
- Numerical fields contain valid numbers

Invalid input does not terminate the program. The user is asked to enter
the value again.

## Project Objective

The main objective of this project is to develop a simple and useful
Python application that demonstrates:

- Functions
- Conditional statements
- Loops
- Lists
- User input
- Input validation
- Modular programming

The system also demonstrates how basic programming can be applied to an
academic performance analysis problem.

## Expected Outcome

After entering student details, the system provides:

1. Predicted Performance Score
2. Performance Level
3. Academic Risk Level
4. Personalized Recommendations

This helps users understand the student's current academic situation and
identify possible areas for improvement.
